# sreyascr.github.io

Portfolio of Shreyas Challiyil, data engineer in Berlin. Live at https://sreyascr.github.io.

Vite + React 19 + TypeScript, Tailwind CSS v4, shadcn/ui (components in `src/components/ui`), and `motion` for animation.

## Run it

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # type-check, build to dist/, copy index.html to 404.html for GitHub Pages
npm run preview   # serve dist/ locally
```

The built site needs a web server (GitHub Pages, or `npm run preview`). Opening `dist/index.html` straight from the file system will not work.

## Where things live

| Path | What |
|---|---|
| `src/components/ui/helix-ribbon-hero.tsx` | The home hero, from 21st.dev (`@kedhareswer/helix-ribbon-hero`), plus four opt-in props: `portraitNode`, `portraitBackground`, linked grid cards (`href`) and `onProjectClick` |
| `src/components/ui/translucent-cassette-player.tsx` | The cassette player from 21st.dev, plus one `tapeLabel` prop; used on the Microphone forensics page |
| `src/components/chess-knight.tsx` | The hero's portrait slot: a knight that leans toward the pointer and makes a knight's move on click |
| `src/components/mic-tape.tsx` | The test tape (Web Audio) and the project-stage tracker beside the cassette |
| `src/components/sales-gallery.tsx` | The six Tableau views on the sales dashboard page |
| `src/data/*.json` | Projects, tools and photo credits, generated by `../_tools/extract.py` from the old static site and `../website_build_scripts` |
| `src/lib/data.ts` | Typed access to the data, project groups, the helix order, page photographs |
| `public/img`, `public/icons` | Photographs (Wikimedia Commons, credited on `/credits`), dashboard screenshots, tool icons |

To add a project, add it to `project_facts.json` (or to the `SALES`-style block in `extract.py`), re-run the extractor, give it a cover in `public/img` and a 1200x800 crop in `public/img/ribbon`, and add its slug to a group in `src/lib/data.ts`.

## Design

Palette from the ui-ux-pro-max skill's "Analytics Dashboard" profile: field `#1E40AF`, type `#F8FAFC`, amber `#D97706`, ink `#1E3A8A`, muted `#475569`, border `#DBEAFE`. Type: Anton for display, Inter Tight for text, both self-hosted with Fontsource (no Google Fonts requests).

## Deploy

`.github/workflows/deploy.yml` builds and publishes `dist/` to GitHub Pages on every push to `main`. In the repository settings, set **Pages > Source** to **GitHub Actions**. The repository has to be public (or on a plan with private Pages) for the site to be served.

Old URLs such as `/about.html` and `/projects/ais.html` redirect to their new paths.
